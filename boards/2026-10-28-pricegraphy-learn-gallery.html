推荐骨架

图解小册

对标《圖解貨幣簡史》内页：一页一钩、左叙事右符号。

  • 每章一张「价签解剖图」（学宇宙金彩图密度）
  • 社媒卡 → 成书页，几乎零改造
  • 宏观史只作开场，立刻落到 sticker
推荐核心

溢价拆解手册

对标站上 Costco / Spot vs retail / Melt：工具感正文。

  • 一章 = 一张价签拆解（spot / 溢价 / 税 / 回购）
  • 附计算器二维码，闭环站上资产
  • 语气直白拆穿，不做说明书腔
附录形态

比价工作簿

空白栏让读者填银楼 / 电商 / Costco 当日价。

  • 章节 = 验算清单（学一口价、克重表）
  • 可续订年度税表附录（美/英/新）
  • 本地化版本：台 / 新 / 美分册
出版组合建议：主书用「圖解貨幣簡史」的页节奏做图解小册外壳；正文章法抄 Costco 溢价拆解 + 一根条三种价；附录做比价工作簿（克 karat 表、熔值区间、$1000 能买什么）。贵金属领航 / 华尔街投资法只借规格与对照表，内页喊单一律剔除。
